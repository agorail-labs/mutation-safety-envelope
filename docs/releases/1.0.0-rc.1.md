# @agorail-labs/mse-reference 1.0.0-rc.1 — release candidate notes

**Status: CANDIDATE — prepared for independent review. Not a
stable release; the current published line remains
`0.4.0-experimental.1`.**

## What this candidate is

The first release candidate for MSE's stable core:
`evaluateAdmissionOnly`, the well-formedness validators,
`deriveSatisfactionRealization`, the core types, and the JSON
Schema export, under the proposed 1.0 contract in
`docs/STABLE-RELEASE-READINESS.md` and `docs/VERSIONING-POLICY.md`.

## Changes from 0.4.0-experimental.1

- No export-name or shape changes (machine-verified identical
  surface: 8 values, 42 types).
- Behavioral fix: `assertAdmissionReportWellFormed` and
  `assertQuoteUnitsWellFormed` now throw `MseViolation` on
  null/non-object input instead of leaking a raw `TypeError`.
- `engines: node >=22`; validated on Node 22/24/26 LTS.
- Documentation: API reference, versioning policy, migration
  guide, support matrix, security policy and audit.

## Known limitations

- `ReferenceProvider` is reference scaffolding, not a production
  integration surface.
- Independent review of this candidate is a pending release gate;
  see `docs/RELEASE-QUALIFICATION.md` for the full gate table.
- Admission is not authorization and not execution — unchanged,
  by design.
